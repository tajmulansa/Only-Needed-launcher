# Only Needed

A minimal Android launcher for using your phone with intention, not muscle memory.

- **Six apps on Home.** The clock, the date and the six apps you chose. Nothing else to scroll.
- **Everything else, on purpose.** Type an app's full name, choose how long you need it, and a small timer counts it down.
- **A red button for hard moments.** Tap it twice for a calm five minute break.
- **Private.** No account, no ads, no internet permission. Everything stays on your phone.

Status: alpha. See [AGENTS.md](AGENTS.md) for how it works and the rules, [docs/RELEASING.md](docs/RELEASING.md) for publishing, [docs/PRIVACY.md](docs/PRIVACY.md) for the privacy policy.
